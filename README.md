# Petent — cereri și sesizări către autorități

Aplicație web care te ajută să scrii cereri, sesizări și plângeri către autoritățile din România.

**Deschide aplicația:** *(link-ul GitHub Pages se completează după publicare)*

## Ce face

- Șabloane pentru cereri și sesizări, cu date din primării și instituții de control.
- Registru cu termene de răspuns și plângeri.
- Export și import al datelor, în fișier JSON.
- Export în `.ics` pentru calendar.

## Confidențialitate

Aplicația nu are cont și nu trimite date pe internet. Datele rămân în browserul tău (`localStorage`) și nu sunt vizibile pentru nimeni altcineva.

## Rulare locală

Deschide `index.html` într-un browser. Nu are nevoie de server.

## Structură

- `index.html` — întreaga aplicație (HTML, CSS, JavaScript și date într-un singur fișier).
